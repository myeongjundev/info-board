## 현재 상태

**여기에 적지 않는다.** [docs/DECISIONS.md](../docs/DECISIONS.md) 에 있다.

전에는 이 자리에 커밋·테스트 수·카드별 통과 여부를 적어 두었는데, 2026-08-28 에
확인해 보니 테스트 162건(실제 201건)·커밋 `7c92f6a`(실제 `f80f5ab`)·능동 작업
19.0h(실제 20.5h)로 **세 값이 전부 낡아 있었다.**

상태를 두 곳에 적으면 갈라진다. T02 에서 난이도 실험 하나가 세 문서에 미시작·
미통과·통과로 각각 적혀 있었던 것이 그것이고, 이 파일이 같은 길로 가고 있었다.
그래서 숫자를 고치는 대신 **자리를 없앤다.**

이 폴더의 날짜별 기록은 **그날의 판단을 남기는 것**이고 현재 상태가 아니다.
지나간 기록은 고쳐 쓰지 않는다 — 고쳐 쓰면 무엇을 왜 바꿨는지가 사라진다.

## 코드 구조

```
src/source/     출처 adapter와 외부 응답 정규화
src/state/      날짜+신호 키, live/replay 공통 upsert, 손상 격리, 비교
src/view/       React 없는 화면 계산 — 브라우저 없이 테스트
src/ui/         React 컴포넌트와 공개 fixture replay 화면
scripts/        수집·스키마 변환·공개 자산 검증·T04 준비상태 감사
test/           node --test 회귀·fixture 전이 검증
data/           records.json(진실의 원천)과 서로 분리된 확장 스냅샷
```

**`view` 와 `ui` 를 나눈 이유**는 변화량·방향·경과시간 계산을 브라우저 없이
검증하기 위해서다. 테스트할 수 없는 자리에 계산이 있으면 손계산 대조를 못 한다.
`review` 스킬이 `ui` 안에 나눗셈이 생기면 잡는다.

## 화면에 있는 것

스크롤 깊이가 곧 신뢰 깊이가 되게 배치했다. 탭을 쓰지 않는다 — 브리프가
`한 화면에 보인다` 를 카드 1·5 의 통과 기준으로 못박았기 때문이다.

```
상단 띠     로고 · 게임 검색 · 설정(대표 게임 고르기)
구획 나브   현재 · 잰 날 · 대조 · 장애 · 시각 · 장르 · 순위 · 움직임 · 순위 이동 · 오래된 게임
            ↑ 누르면 갈아끼우지 않고 그 구획으로 내려간다

1층  대표값 · 단위 · 잰 날 · 잰 시각 · 어제와 비교        15초 판정 구역
     출처 · 날짜별 기록
2층  잰 날 카드 줄 · 대조(접이식) · 장애 재현 5종          근거
3층  같은 날 다른 시각 · 장르 · 순위 · 움직임 ·            확장
     순위 이동 · 아직 살아 있는가
```

**API 를 더 붙이지 않았다.** 3층까지 전부 같은 기록 파일에서 나온다.
예외는 표지 그림 하나이고 그건 값이 아니다 ([CLAUDE.md](../CLAUDE.md) 5번 예외).

## 명령어

```bash
npm test                    # 단위 테스트. 의존성 없음
npm run dev                 # 화면 (5174)
npm run audit:t04 -- --online  # C01~C35 준비상태와 공개 접근 재검사
node scripts/verify-assets.mjs # 공개 fixture 원본 17개 hash 대조
node scripts/collect.mjs    # 하루 한 건. 손으로 돌리지 않는다 ⚠
node scripts/probe-hours.mjs   # 시각별 표본. 아무 때나 돌려도 된다
```

`/review` 스킬은 커밋 전에 돌린다. 오늘 실제로 다섯 번 돌렸고 **그중 두 번이
결함을 잡았다** — `ui` 안의 나눗셈, 그리고 리뷰 자신의 사각지대.

### 화면은 스크린샷으로 봐야 한다

**텍스트 계측으로 "화면 확인했다" 고 말하지 않는다.** `innerText` 로 읽으면
줄바꿈도 정렬도 흔적이 없다. 2026-08-28 에 그 둘이 동시에 나왔다 —
[결함 15·16](../docs/DEFECTS.md) 이고, **첫 스크린샷 한 장**에서 같이 잡혔다.
그 전 세 세션은 텍스트만 보고 넘어갔다.

앱 안의 브라우저 pane 이 화면에 안 떠 있으면 페이지가 프레임을 합성하지 않아
스크린샷이 5초 타임아웃으로 죽는다. 텍스트는 읽히는데 그림만 안 되므로
**되는 줄 알기 쉽다.** 그때는 **연결된 Chrome** 으로 옮긴다.

배치를 볼 때는 눈보다 좌표가 정확하다. 이렇게 재면 어긋난 것이 숫자로 나온다.

```js
[...document.querySelectorAll('.sales-rank-list li')]
  .map(li => Math.round(li.querySelector('strong').getBoundingClientRect().left))
// 값이 하나면 열이 맞는다. 둘 이상이면 어긋난 행이 있다
```
