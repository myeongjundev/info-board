### 2. 성인 분류 접기

`#/charts` 한국 매출 20위에 성인 게임 제목과 표지가 아무 확인 없이 떠 있었다.
**커밋된 데이터에 있었으므로 공개 주소에도 그대로 나가 있었다.**

**판별을 추측하지 않고 실측으로 정했다.** Steam 이 무엇을 막는지 직접 열어 봤다.

```
4924510  [1,3,4,5]  → login/?redir=agecheck   막는다
3718190  [1,3,4,5]  → login/?redir=agecheck   막는다
3308670  [1,5]      → 정상 페이지             안 막는다
730      [2,5]      → 정상 페이지             안 막는다
```

`content descriptor` 에 **3 또는 4** 가 있을 때만 접으면 Steam 의 자체 게이트와
정확히 일치한다. **1 이나 2 로 넓히지 않는다** — 정상 게임까지 접히면 우리가 자료를
가리는 쪽이 된다. `test/contentDescriptors.test.js` 가 이 표본을 그대로 들고 있어서
나중에 규칙을 넓히면 거기가 먼저 깨진다.

**접는 것과 안 접는 것.**

| | |
|---|---|
| 접음 | 제목 글자, 표지 그림 |
| **안 접음** | **순위 · 가격 · 할인율 · 상점 링크** |

숫자는 하나도 안 움직인다. 공개된 순위를 지우면 그게 조작이다. 규칙 5 의 표지 그림
예외가 "그림은 값이 아니다" 라고 쓴 것과 같은 자리다.

**왜 접는 쪽이 원본에 가까운가.** Steam 이 이 항목을 비로그인 방문자에게 안 보여준다.
우리 화면이 **원본보다 더 많이 보여주고 있었다.**

**펼치기 버튼은 안 만들었다.** 나이 확인을 흉내 낼 방법이 없으니 확인은 원래 하는
쪽이 하게 둔다. 상점 링크는 그대로라 보려는 사람은 Steam 으로 가고 거기서 막힌다.
`<a>` 안에 버튼을 중첩하는 접근성 문제도 함께 사라졌다.

**세 출처를 한 판별로 묶었다.** 필드 모양이 다 달라서 추출만 세 군데다.

```
판매 차트      item.content_descriptorids     배열
출시 캘린더    data-ds-descids="[3,4]"        문자열
인기 100 할인  data.content_descriptors.ids   객체
```

**추가 네트워크 호출은 0개다.** 차트 응답이 이미 갖고 있었다.

**스키마 가드.** descriptor 를 한 건도 못 읽으면 응답 형식이 바뀐 것으로 보고
스냅샷을 덮지 않는다. 안 넣으면 어느 날 조용히 다 펼쳐진 채 배포된다.

**확인.** 한국 탭·글로벌 탭 각각 1건씩 접히고 순위 자리는 남는다. 접힌 개수를 화면이
스스로 밝힌다.

### 3. 비공식 경로 — 유지로 닫았다 (규칙 5-0 신설)

근거를 "우리 프로젝트에 공식 출처도 있으니까" 로 적지 않았다. 구역마다 따로 서야
하고, 그 답은 심사에서 못 쓴다.

**실제 근거 셋.**

1. **과제가 경로를 제한한 적이 없다.** 카드 2 원문이 `특정 API나 호출 경로는 지정하지
   않는다` 다. 금지는 우리가 만든 규칙이고, 그것은 대표값 출처를 고를 때 세운 기준이다.
2. **채점되는 값은 전부 공식 경로 위에 있다.** 대표값은 `GetNumberOfCurrentPlayers`
   에서 오고 기록·비교·순위가 거기서 나온다. 보조 구역은 채점되는 숫자를 하나도
   만들지 않는다.
3. **각 구역이 화면에서 스스로 밝힌다.**

**"나무위키는 왜 안 되고 이건 되나" 의 답** — 나무위키는 대표값 자리에 놓으려 했고,
이 경로들은 보조 구역에 있으며 채점되는 값을 만들지 않는다.

**깨지는 조건도 적었다.** 보조 구역 값이 대표값 계산에 들어가거나, 화면이 비공식
경로를 공식이라 부르면 다시 판단한다.

### 4. 어긋난 표현 하나
