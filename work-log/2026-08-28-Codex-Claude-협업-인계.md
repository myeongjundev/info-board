## 먼저 읽을 결론

C07은 더 이상 판단 대기 상태가 아니다. 다음으로 확정했다.

- live Steam Reading은 `sourceTime: null`을 저장한다.
- 화면에는 `출처 관측 시각: 제공되지 않음 · Steam API 미제공`을 표시한다.
- `fetchedAt`은 별도의 `조회 시각`으로 표시한다.
- HTTP `Date` 헤더는 응답 시각이지 원천 관측 시각이 아니므로 대신 쓰지 않는다.
- 대표 소재 변경은 비용뿐 아니라 데이터 계보 전체를 바꾸므로 별도 결정 없이 하지 않는다.
- 공개 fixture의 `source_time`은 제공된 값을 그대로 보존·표시한다.

없는 시각을 만들어 C07을 통과한 것처럼 보이게 하지 않는 것이 이 프로젝트의
Reading 불변식과 맞는다. live의 `null`도 저장값·화면값·향후 영수증 대조에서 같은
의미로 유지한다.

## Git으로 작업을 주고받는 규칙

사용자가 학원에 있어 로컬 파일을 직접 전달하기 어려우므로 **원격 저장소를 유일한
공유 기준**으로 쓴다.

한 번에 한 에이전트만 main의 작성자가 된다.

작업 시작:

```bash
git status --short --branch
git pull --ff-only
```

작업 종료:

```bash
npm test
git diff --check
git status --short
git add <이번 작업 파일만>
git commit -m "<한 가지 목적을 설명하는 메시지>"
git push origin main
```

- 다른 에이전트의 미커밋 파일을 복원·삭제·덮어쓰지 않는다.
- `git reset --hard`, 강제 push, `records.json` 수기 입력을 하지 않는다.
- 원격이 앞섰으면 강제로 밀지 말고 멈춘 뒤 충돌 파일과 원격 커밋을 보고한다.
- 동시에 작업해야 한다면 별도 브랜치에 커밋하고, Codex가 리뷰 후 main에 통합한다.
- 공개 fixture 원본 17개는 수정하지 않는다.
- 판매·스트리밍 확장 구역을 더 늘리지 않는다.
