# 카드 점검

과제 원문: [docs/research/오늘의 진짜 정보판.md](../../../docs/research/오늘의%20진짜%20정보판.md)

**추측으로 채우지 않는다.** 각 항목은 실제로 확인한 뒤에만 통과로 적는다.
확인 못 한 것은 "미확인" 으로 남긴다 — 빈칸보다 낫다.

## 카드별 통과 기준과 확인 방법

### 카드 1 — 값의 맥락
> 현재값·단위·출처·조회 시각이 한 화면에 보인다.

공개 주소를 열어 네 가지가 **스크롤 없이** 보이는지 본다.
화면값과 `data/records.json` 의 같은 날짜 값이 같은지 대조한다.

### 카드 2 — 비밀키와 호출 경로
> 출처 주소가 화면에 보이고 한 번 누르면 원자료 페이지가 열린다.

링크를 실제로 눌러 JSON 이 열리는지 본다.

```bash
git log -p | grep -iE "api[_-]?key|token|secret|password" | head
grep -rniE "api[_-]?key|token|secret" src/ scripts/ --include="*.js" | head
```

이 출처는 키를 요구하지 않으므로 **SECRET COUNT = 0 이 기본이다.**

### 카드 3 — 실패를 구분해 보여주기
> 현재 자료인지 오래된 자료인지 상태 문구로 구분된다.

브리프가 **"모의실험한다"** 로 명시했다. 실제 API 를 죽일 필요 없다.
5종(`TIMEOUT · AUTH · RATE_LIMIT · OFFLINE · SCHEMA`)이 **서로 다른 문구**로
나오는지, 마지막 정상값이 살아 있는지, 다시 시도로 복구되는지 각각 본다.

### 카드 4 — 하루 한 번 기록
> 날짜별 값은 같은 날짜가 중복되지 않게 목록에 보인다.

```bash
node scripts/collect.mjs && node scripts/collect.mjs   # 두 번 돌려도 안 늘어야 한다
```

서로 다른 **실제** 날짜 2건이 공개 주소에서 보이는지 확인한다.

### 카드 5 — 어제와 비교 검증
> 이전 값과 현재 값의 차이·방향·단위가 한 화면에 보인다.

원자료 → 저장값 → 계산값 → 화면값을 날짜별로 대조하고 **손으로 한 번 계산해서**
화면 결과와 맞는지 본다. 결과는 `docs/CROSSCHECK.md` 에 적는다.
