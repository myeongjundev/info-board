## 무엇이 보이면 통과인가요

### 1단계 — 첫 화면 (카드 1 · 4 · 5)

스크롤하지 않고 이것들이 한 화면에 보인다.

| 보이는 것 | 예 |
|---|---|
| 현재값과 단위 | `551,673 명` |
| **잰 날** | `2026-08-27` · `Asia/Seoul` |
| **잰 시각** | `2026-08-27 09:59` · `15분 전` |
| 이전 기록 대비 차이·방향·단위 | `▲ +51,673 명 (+10.33%)` |
| 손계산 식 | `손계산 551673 − 500000 = 51673 명` |
| 날짜별 기록 | 날짜마다 **한 줄씩만** |
| 상태 배지 | `오늘 잰 값` |

**잰 날과 잰 시각이 서로 다른 칸에 있는지** 보면 된다. 이 둘은 다르다.

> 기록이 하루치뿐이면 비교 자리에 숫자 대신
> `비교할 이전 기록이 아직 없다` 가 나온다. **이게 정상이다.**
> 자료가 없는데 변화값을 만들어내지 않는다.

### 2단계 — 출처 (카드 2)

누르면 이 주소가 그대로 열리고 JSON 이 보인다.

```
https://api.steampowered.com/ISteamUserStats/GetNumberOfCurrentPlayers/v1/?appid=730
→ {"response":{"player_count":551673,"result":1}}
```

**이 API 는 인증 키를 요구하지 않는다.** 화면에도, 배포 파일에도, 네트워크 요청
주소에도, Git 기록에도 비밀값이 없다.

> ⚠️ **링크 속 숫자는 화면의 숫자와 다르다. 그게 맞다.**
> 동시접속자는 부르는 순간의 사람 수라 1초 뒤면 달라진다. 화면의 값은
> 잰 시각의 값이고, 그 사실이 화면에 적혀 있다.
> 확정된 하루치 집계가 아니라는 것을 숨기지 않는 것이 이 정보판의 요점이다.

### 3단계 — 장애 (카드 3)

`offline` 을 누르면

- 위에 **`재현 모드`** 띠가 뜬다 — 실제로 자료를 부르지 않고 그 상태를 만들어 보인다
- 배지가 **`오래된 자료`** 로 바뀐다
- **숫자는 그대로 남는다** — 마지막 정상값을 버리지 않는다
- **잰 시각이 지금으로 바뀌지 않는다** — 아까 그 시각 그대로다
- `다시 시도` 단추가 있다

나머지 넷도 눌러 보면 **서로 다른 문구**가 나온다.

| 누르면 | 나오는 문구 |
|---|---|
| `timeout` | 응답이 오지 않았다 |
| `auth` | 접근이 거부됐다 |
| `rate-limit` | 호출 제한에 걸렸다 |
| `offline` | 연결이 끊겼다 |
| `schema` | 응답 형식이 달라졌다 |

`정상으로` 를 누르면 복구된다.

**마지막 정상값조차 없는 상태**를 보려면 주소 끝에 `&empty=1` 을 붙인다.
숫자 자리에 `—` 가 나오고 값을 만들어내지 않는다.

```
https://myeongjundev.github.io/info-board/?fault=schema&empty=1
```

## 안 될 때

| 증상 | 확인 |
|---|---|
| **화면이 비어 있다** | 주소 끝에 `/` 가 있는지. `?fault=` 가 붙어 있으면 지운다 |
| **`자료 없음` 이 뜬다** | 기록 파일이 비었다는 뜻이다. [data/records.json](https://github.com/myeongjundev/info-board/blob/main/data/records.json) 을 직접 열어 본다 |
| **`오래된 자료` 가 뜨는데 재현 모드가 아니다** | 수집이 밀린 것이다. 값은 진짜고 잰 시각도 진짜다. 며칠 밀렸는지 배지에 적혀 있다 |
| **출처 링크의 숫자가 화면과 다르다** | **정상이다.** 위 2단계 설명 참조 |
| **날짜가 하루 어긋나 보인다** | 기준 시간대는 `Asia/Seoul` 이다. 화면 맨 아래에 적혀 있다 |
| **주소가 404 다** | 배포가 아직 안 끝났다. [Actions](https://github.com/myeongjundev/info-board/actions) 에서 `배포` 가 초록인지 본다 |

이 정보판의 날짜별 기록은 브라우저가 아니라 **저장소에 커밋으로 쌓인다.**

- [data/records.json](https://github.com/myeongjundev/info-board/blob/main/data/records.json) — 화면이 읽는 바로 그 파일
- [커밋 이력](https://github.com/myeongjundev/info-board/commits/main/data/records.json) — 언제 무엇이 들어갔는지

누가 열어도 같은 기록을 본다. 손으로 채운 날짜는 없다 — 동시접속자는 순간값이라
과거를 잴 수 없고, 수집기가 오늘이 아닌 날짜를 **호출 전에 거부한다.**
