# GAME PULSE

### 오늘 Steam 에 몇 명이 있는가

**https://myeongjundev.github.io/info-board/**

지금 이 순간 Counter-Strike 2 를 하고 있는 사람이 몇 명인지 보여준다.
그리고 **그 숫자를 믿어도 되는지 함께 보여준다.**

---

## 무엇을 보여주는가

값 하나다. **매일 10:10 (KST) 에 잰 Steam 동시접속자 수.**

그 옆에 그 숫자를 읽는 데 필요한 것들이 함께 놓인다.

- 단위와 **잰 날**
- **잰 시각** — 위와 다르다. 이 둘을 섞는 것이 가장 흔한 거짓말이다
- 원자료 주소 — 누르면 실제 응답이 열린다
- 이전 기록과의 차이·방향·단위, 그리고 **손계산 식**
- 날짜별 기록 — 같은 날짜가 중복되지 않는다

그 아래에 같은 기록에서 꺼낸 이야기 넷이 더 있다.

- 🎮 **장르로 묶어 보기** — 장르는 원자료가 안 줘서 우리가 붙였다. 그래서 장르마다 든 게임을 다 펼치고 게임 수를 함께 적는다
- 🏆 **오늘 잰 것 — 사람 수 순** — 재는 게임 전부를 줄 세운다. 이전 기록이 필요 없어 첫날부터 보인다
- 🚀 **어제보다 움직인 게임** — 오른 게임과 내린 게임
- 💀 **아직 살아 있는가** — 26년 된 게임에 아직 몇 명이 남아 있는가

**API 를 더 붙이지 않았다.** 매일 재는 게임 16개의 같은 기록에서 전부 나온다.
순위 옆의 %는 **이 16개 안에서의 비중**이다. Steam 전체 동시접속자는 이
엔드포인트가 주지 않으므로 모르고, 모르는 것을 분모로 쓰지 않는다.

## 왜 이렇게 만드는가

값 하나를 크게 띄우는 것은 쉽다. 어려운 것은 **그 값을 믿어도 되는지 함께 보여주는 일** 이다.

- 자료가 안 오면 마지막 정상값을 보여주되 **잰 시각을 갱신하지 않는다.**
  오래된 값에 지금 시각을 붙이는 것이 가장 흔한 거짓말이다.
- 정상값이 한 번도 없으면 숫자 자리에 숫자를 넣지 않는다. `—` 로 둔다.
- timeout · 인증 실패 · 호출 제한 · 오프라인 · 응답 형식 변경을 **서로 다른 상태로** 구분한다.
- 날짜별 기록은 브라우저가 아니라 **이 저장소에 커밋으로 쌓인다.**
  누가 열어도 같은 기록을 본다. [기록 파일](data/records.json) ·
  [커밋 이력](../../commits/main/data/records.json)

### 이 자료의 약점을 화면에 적는다

동시접속자는 **부르는 순간의 사람 수**다. 확정된 하루치 집계가 아니다.

그래서 화면의 출처 링크를 누르면 **화면의 숫자와 다른 숫자가 나온다.** 실제로 재 봤다.

| 시각 (UTC) | 값 |
|---|---:|
| 00:04 | 572,811 |
| 00:59 | 551,673 ← 기록된 값 |
| 01:27 | 537,072 |

숨기면 "화면값이 원자료와 일치한다" 를 못 지킨 것이 되고, 드러내면 이 정보판이
하려는 말 그 자체가 된다. 그래서 **화면에 그대로 적었다.**

그리고 순간값은 과거를 되짚을 수 없다. 수집이 하루 빠지면 그날은 영영 빈칸이다.
지금 재서 어제 칸에 넣는 것은 측정이 아니라 조작이므로, 수집기가 오늘이 아닌
날짜를 **호출 전에 거부한다.**

## 출처

[Steam Web API](https://partner.steamgames.com/doc/webapi/ISteamUserStats) — 공개 문서, 인증 키 없음.

```
GET https://api.steampowered.com/ISteamUserStats/GetNumberOfCurrentPlayers/v1/?appid=730
→ {"response":{"player_count":551673,"result":1}}
```

**쓰는 엔드포인트는 이것 하나뿐이다.** 게임 이름은 원자료가 주지 않으므로 우리가
표에 적었고, 원자료와 잇는 열쇠는 appid 다. 이름을 얻자고 문서화되지 않은
`store.steampowered.com` 경로를 부르지 않는다.

비밀값은 없다. **SECRET COUNT = 0** — 검사 내역은 [대조표](docs/CROSSCHECK.md) 5절.

## 어떻게 도는가

```
GitHub Actions (매일 01:10 UTC)
        ↓
게임 16개 조회 → 날짜+appid 로 upsert
        ↓
data/records.json 에 커밋          ← git 이력이 그대로 감사 로그
        ↓
GitHub Pages 로 배포
        ↓
화면이 그 파일을 fetch 해서 읽는다
```

Steam 은 CORS 를 열어 주지 않아 브라우저가 직접 못 부른다. 그래서 화면에
`LIVE` 라고 쓰지 않는다 — 방문자가 보는 값은 최대 24시간 지난 값이다.

## 직접 돌려보기

의존성 없이 수집기만 돌릴 수 있다. Node 22 이상.

```bash
git clone https://github.com/myeongjundev/info-board.git
cd info-board

node scripts/collect.mjs   # 값이 제대로 오는지 (설치 필요 없음)
npm test                   # 단위 테스트 134건

npm install
npm run dev                # 화면
```

## 구조

```
src/source/     출처. definition.js 하나만 고치면 다른 데이터로 옮겨진다
src/state/      기록. 날짜+appid 키, 중복 방지, 손상 격리, 비교
src/view/       화면 계산. React 를 import 하지 않아 브라우저 없이 테스트된다
src/ui/         React 컴포넌트. 계산을 하지 않는다
scripts/        Actions 가 돌리는 진입점
data/           진실의 원천
```

`view` 와 `ui` 를 나눈 이유는 변화량·방향·경과시간 계산을 브라우저 없이
검증하기 위해서다. 테스트할 수 없는 자리에 계산이 있으면 손계산 대조를 못 한다.
